# App UI Kit — operational shell (Ponto)

Recreates the logged-in app: 256-px sidebar accordion, topbar, breadcrumb, and a Ponto dashboard built with the shared primitives.

## Components
- `AppShell.jsx` — sidebar + main shell
- `Sidebar.jsx` — accordion menu, business badge, user footer
- `PageHeader.jsx` — primary-tinted icon plate + title + description + action slot
- `KpiCard.jsx` — tone variants (default/success/warning/danger/info), delta arrow
- `StatusBadge.jsx` — domain-mapped (intercorrencia / payment / prioridade / rep)
- `PresenceStrip.jsx` — live avatar grid with status dots
- `ActivityFeed.jsx` — chronological timeline of REP-P punches
- `Icon.jsx` — tiny inline SVG set (Lucide-style 1.5 stroke), no CDN required

Open `index.html` for the Ponto dashboard.
