# Site UI Kit — marketing surface (oimpresso.com)

Recreates `/` (homepage) and the structure used by `/pricing`. Pixel-faithful to `resources/js/Components/Site/*.tsx` in the source repo.

## Components

- `SiteHeader.jsx` — sticky, blurred translucent header with `oi`-square wordmark + nav + CTA
- `Hero.jsx` — radial primary bloom + 3-line display heading + CTA pair + dashboard mockup plate
- `DashboardMockup.jsx` — fake browser chrome wrapping a mini-dashboard (KPI tiles + sparkline)
- `SocialProof.jsx` — sector chips row + 3-up stats
- `FeatureGrid.jsx` — 8 module cards in a 4-col grid (📐 🏭 🛒 📦 🧾 ⏱️ 💳 📊)
- `PricingTiers.jsx` — 3 tiers with billing toggle (mensal / anual −20%); Profissional highlighted with primary border + tinted shadow
- `SiteFooter.jsx` — 5-col link grid + copyright

Open `index.html` for the assembled homepage.
