# Casos — Devolução

- UC-DEV-01 Dado item com 3 unidades vendidas, quando digito 5, então o campo trava em 3.
- UC-DEV-02 Dado nenhuma quantidade preenchida, então "Salvar devolução" fica desabilitado.
- UC-DEV-03 Dado 1 de 3 unidades devolvidas, então o total devolvido é o preço unitário × 1.
- UC-DEV-04 Dado que cheguei pela lista de POS, então a venda de origem já vem carregada.
