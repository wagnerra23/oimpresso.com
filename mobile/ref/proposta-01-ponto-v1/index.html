(d) Margens reais do aparelhosubstitui o padding fixo de moldura
<meta name="viewport"
  content="width=device-width, initial-scale=1, viewport-fit=cover">

/* sai */
.oi-app[data-platform="android"] { padding: 40px 0 24px; }

/* entra */
.oi-app .top {
  padding-top: calc(12px + env(safe-area-inset-top));
}
.tabbar {
  padding-bottom: calc(6px + env(safe-area-inset-bottom));
}
.oi-app { padding-left: env(safe-area-inset-left);
          padding-right: env(safe-area-inset-right); }

Medido pela sessão do app no emulador Android 16: o padding fixo escondia a barra de abas atrás da barra de gestos. Com viewport-fit=cover o Android e o iOS informam as margens reais; fora do aparelho o env() vale 0 e o desenho fica igual. Esta folha já usa as duas regras.
